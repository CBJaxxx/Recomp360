# Recomp360

An Xbox 360 style dashboard for recompiled Xbox 360 games on Windows PC.

- Create a profile (with an optional pass code) and sign in.
- Make your avatar with the real Xbox 360 Avatar Editor; games that use avatars use yours.
- Browse the recomps, press **Install**, and play them from your game library.

## Download

**[Recomp360-Setup.exe](https://github.com/CBJaxxx/Recomp360/releases/latest/download/Recomp360-Setup.exe)** for Windows 10 and 11 (64-bit). No admin rights needed.

## You need your own games

Recomp360 never downloads any game files. The first time you play a recomp, it asks for your own copy of the game (a disc image or Xbox Live Arcade file) and any title update and DLC you own. After that, the game starts straight away.
